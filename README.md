# Decor Plus — WhatsApp Business Multi-Account CRM & Automation System
نظام إدارة علاقات العملاء (CRM) والأتمتة متعدد الحسابات لشركة Decor Plus للأخشاب الديكورية والأرضيات الفاخرة

---

## 1. نظرة عامة على المشروع (Overview)

تم بناء هذا النظام خصيصاً لشركة **Decor Plus** الرائدة في مجال الأرضيات الخشبية الهندسية (Engineered Wood)، والتيك الطبيعي البرازيلي (Brazilian Teak)، والإيروكو (Iroko Teak)، وتكسيات أسطح اليخوت والمشاريع الخارجية.

يعمل النظام بشكل كامل عبر ربط تطبيق واتساب للأعمال العادي (**WhatsApp Business Mobile Application**) باستخدام جلسات الويب الرسمية عبر رمز الاستجابة السريعة (**QR-based Linked Sessions**)، دون الحاجة إطلاقاً إلى:
- حساب Meta Developer
- WhatsApp Cloud API
- WhatsApp Business Platform API المسبقة الدفع
- تكاليف إضافية لكل رسالة

## 2. تقييم ومقارنة مكتبات الربط (Library Evaluation)

| معيار المقارنة | Baileys (`@whiskeysockets/baileys`) - **تم اختياره** | whatsapp-web.js |
| :--- | :--- | :--- |
| **آلية العمل** | بروتوكول WebSocket نقي ومباشر مع تشفير Protobuf و Noise | متصفح Chromium خفي (Puppeteer Browser Automation) |
| **استهلاك الذاكرة (RAM)** | **25 - 45 ميجابايت** لكل حساب (إجمالي 7 حسابات < 300MB) | 450 - 700 ميجابايت لكل حساب (يتطلب 3.5GB - 5GB RAM لـ 7 حسابات) |
| **استهلاك المعالج (CPU)** | خفيف جداً، معالجة رسائل ثنائية بدون عرض مرئي | عالي جداً بسبب محرك التصيير و DOM في كل متصفح |
| **استقرار الجلسات على Windows** | استقرار تام، استعادة مفاتيح التشفير تلقائياً بعد إعادة التشغيل | عرضة لانهيار Chromium وتراكم العمليات المعلقة (Zombie Processes) |
| **صمود التحديثات** | لا يتأثر بتغيير كلاسات CSS أو تصميم واجهة WhatsApp Web | يتعطل فوراً عند تغيير WhatsApp Web لأسماء الفئات في الـ DOM |
| **حكم المهندس المعماري** | **الخيار الإنتاجي الأفضل والوحيد المناسب لتشغيل 7 حسابات متزامنة** | غير عملي لخوادم الحسابات المتعددة على جهاز محلي |

### تحذيرات الأمان ومكافحة الحظر (Anti-Ban Protections)
> [!WARNING]
> إن كافة مكتبات الربط غير الرسمية تخضع لسياسات استخدام واتساب. لتجنب تقييد الحسابات أو حظرها، قام النظام بتطبيق الإجراءات الوقائية التالية:
> 1. **تأخير عشوائي بشري (Humanized Jitter):** فاصل زمني عشوائي من 3 إلى 7 ثوانٍ بين الرسائل المجدولة.
> 2. **مفتاح الأمان العام (Global Kill Switch):** إمكانية إيقاف كافة الردود التلقائية بضغطة زر واحدة في حالات الطوارئ.
> 3. **فلترة غير الراغبين (Opt-Out Engine):** استبعاد فوري لأي عميل يطلب "إلغاء الاشتراك" أو "Stop".
> 4. **المطابقة الصارمة التامة (Strict Exact Match):** تمنع التكرار اللانهائي للردود التلقائية.

## 3. الأقسام الـ 14 المكتملة في واجهة النظام (Full RTL Arabic UI)

1. **لوحة التحكم (Dashboard):** مؤشرات أداء لحظية محسوبة من قاعدة بيانات SQLite الحقيقية، وإحصائيات الحسابات المتصلة، وتوزيع العملاء.
2. **حسابات واتساب (WhatsApp Accounts):** إدارة متزامنة لما يصل إلى 7 حسابات مستقلة، مع توليد رموز QR حقيقية، واسترجاع تلقائي للجلسات بعد إعادة التشغيل.
3. **صندوق الوارد الموحد (Unified Inbox):** واجهة محادثات حية تدعم التبديل بين الحسابات، عرض الرسائل الواردة، وإرسال الرسائل عبر الحساب المحدد يدوياً.
4. **إدارة العملاء (Customers):** جدول بيانات شامل، بحث وفلترة متقدمة، إضافة وتعديل العملاء، ودمج السجلات المكررة بأمان.
5. **قوائم وتصنيفات العملاء (Customer Lists & Segments):** تقسيم العملاء حسب نوع الخشب (هندسي، تيك، ديكينج)، وحساب عدد المستلمين المؤهلين مع استبعاد غير الراغبين.
6. **الردود التلقائية (Automatic Replies):** محرك مطابقات صارم مع معالجة الألف وتجاهل التشكيل ومختبر مباشر لاختبار الكلمات (Tester Playground).
7. **منشئ القوائم التفاعلية (Interactive Menu Builder):** محاكي هاتف محمول لمعاينة شكل القوائم مع الاعتماد على القوائم النصية المرقمة المعتمدة.
8. **مسارات الأتمتة (Automation Workflows):** مخططات مرئية لربط الشروط بالإجراءات وتعيين الموظفين.
9. **قوالب الرسائل الجاهزة (Message Templates):** قوالب بمتغيرات ديناميكية مثل `{{customer_name}}` و `{{business_name}}`.
10. **المتابعات والرسائل المجدولة (Scheduled Follow-ups):** طابور رسائل يتحمل انقطاع السيرفر ويعاود الإرسال في المواعيد المحددة.
11. **إدارة الموظفين (Employee Management):** توزيع الصلاحيات وتتبع المحادثات المسندة لكل مهندس ديكور أو موظف مبيعات.
12. **الاستيراد والتصدير (Import & Export):** تصدير حقيقي لمصنفات Excel (`.xlsx`) و CSV، واستيراد مرن مع مطابقة الأعمدة ومعالجة التكرار.
13. **سجلات النشاط والمراجعة (Activity Logs):** سجل أمني غير قابل للتعديل لكافة أحداث النظام.
14. **الإعدادات والأمان (Settings):** ضبط فترات التأخير البشري، الحد الأقصى للحسابات، وخيارات معالجة النصوص.

## 4. تعليمات التثبيت والتشغيل (Quick Start)

### المتطلبات
- **Node.js**: الإصدار 20 فأعلى (تم الاختبار والتأكيد على Node v24).
- هاتف محمول مثبت عليه تطبيق **WhatsApp Business**.

### خطوات التشغيل
1. افتح موجه الأوامر (Terminal / Command Prompt).
2. انتقل إلى مجلد المشروع:
   ```bash
   cd C:\Users\Elmostawred\.gemini\antigravity\scratch\decor-plus-crm
   ```
3. شغّل السيرفر:
   ```bash
   node server.js
   ```
4. افتح المتصفح على الرابط:
   ```
   http://localhost:3000
   ```
5. توجه إلى قسم **"حسابات واتساب"**، اضغط على **"بدء الاتصال ومسح QR"**، وامسح الرمز من هاتفك عبر **WhatsApp Business > الأجهزة المرتبطة > ربط جهاز**.
